타임어택 PWA - Windows 원클릭 테스트
===================================

1. 이 ZIP 파일을 반드시 먼저 압축 해제합니다.
2. 압축을 푼 폴더에서
   "타임어택_PC테스트_실행.bat"
   파일을 더블클릭합니다.
3. 잠시 후 기본 브라우저에서
   http://localhost:8080
   이 자동으로 열립니다.
4. 타임어택 PWA를 실제 웹앱처럼 테스트합니다.
5. 종료할 때 검은 실행창에서 Ctrl + C 를 누릅니다.

주의
- index.html을 직접 더블클릭하지 마세요.
- Windows에 Python이 설치되어 있어야 합니다.
- Windows 보안 경고가 나오면 파일의 출처를 확인한 뒤 실행 여부를 결정하세요.
- 화면 변경이 반영되지 않으면 Ctrl + Shift + R로 새로고침하세요.

확인 권장 순서
홈 → 작전 설정 → BGM → START → 잠깐 멈춤/ISSUE → 다시 집중 →
완료 → 설정 → 이름 변경 → 기본 음악 변경
