타임어택 PWA 최종 검토본 - Windows PC 테스트

1. ZIP을 반드시 압축 해제합니다.
2. START_PC_TEST.bat 을 더블클릭합니다.
3. 브라우저가 localhost:8080 으로 자동 실행됩니다.
4. 8080이 사용 중이면 8081을 자동 사용합니다.
5. 종료할 때 검은 서버 창을 닫습니다.

권장 테스트 순서
홈 → 재능/학교/영어 → 작전 설정 → 과제 텍스트 입력 → 마이크 음성입력 →
10/15/25분 또는 직접 시간입력 → BGM → 작전 공유 → START →
움직이는 아날로그 현재시각 → 타임어택 카운트다운 → 잠깐 멈춤/ISSUE →
다시 집중 → 완료 → 결과 공유 → 설정 → 이름/기본 음악 변경

공유 확인
- 모바일: 운영체제 공유창이 열리고 카카오톡을 선택하는 방식입니다.
- PC: 공유창을 지원하지 않으면 실제 클립보드 복사를 시도합니다.
- 복사 성공이 확인된 경우에만 '복사했어요' 메시지를 표시합니다.
- 자동 복사가 실패하면 공유 문구를 직접 선택/복사할 수 있는 창을 표시합니다.

음성입력
- Chrome 계열에서 Web Speech API를 지원할 때 동작합니다.
- 지원하지 않는 브라우저에서는 텍스트 입력을 사용하도록 안내합니다.
