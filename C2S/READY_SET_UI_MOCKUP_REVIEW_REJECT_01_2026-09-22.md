# READY & SET UI MOCKUP REVIEW — REJECT 01 — 2026-09-22

Status: REJECTED / DO NOT USE AS VISUAL BASELINE
Scope: generated Weekly + Daily mockup after three-screen standard lock

## Why this mockup fails TAKY / Ready locked criteria

### 1. Weekly screen drift
FAIL:
- Weekly became an illustrated full-island game map instead of a compact timetable/weekly overview.
- Schedule readability lost to decorative geography.
- Fixed commitments / Planner DATED TODO / free windows are not legibly distinguished.
- The screen is visually closer to a world-map home than `이번 주 여정`.

Correct direction:
- `이번 주 여정` remains a schedule-first weekly board.
- Island/Base Camp language is atmospheric framing only.
- The user should understand the week before noticing the illustration.

### 2. Daily screen drift
FAIL:
- Daily became a generic gamified task timeline.
- Too many decorative signs/characters and encouragement bubbles.
- Visual noise competes with chronological execution.
- Commitment vs TODO vs free window distinction remains weak.

Correct direction:
- `오늘의 탐험길` is a vertical timetable first.
- Route metaphor is subtle.
- Current/next item hierarchy is primary.

### 3. Character ownership violation
FAIL:
- fixed child/crew characters were invented and embedded.
- Ready must not define character identity or crew visuals.

Correct direction:
- character/crew slot only.
- actual character assets arrive from upstream character/crew system.

### 4. Navigation violation
FAIL:
- new bottom navigation was invented.
- Timer/Weekly/Daily connection must not introduce an unapproved persistent navigation system.

Correct direction:
- preserve existing app navigation contract.
- do not invent new global tabs for mockup convenience.

### 5. Timer contamination
FAIL:
- prior generation included a newly invented timer visual despite Timer being confirmed and asset-ready.

Correct direction:
- Timer is excluded from visual redesign.
- use only as fixed comparison/connection anchor.

### 6. World metaphor overuse
FAIL:
- ONE ISLAND was interpreted as “show the whole island prominently on every planning screen.”
- This created RPG/map-first UI.

Correct direction:
- ONE ISLAND controls continuity/topology, not illustration density.
- Base Camp atmosphere should be felt through small spatial cues, not dominate the schedule.

### 7. Copy drift
FAIL:
- extra motivational copy and labels were invented beyond the locked wording.
- child-facing copy became verbose.

Correct direction:
- Weekly: `이번 주 여정`
- Daily: `오늘의 탐험길`
- Timer: locked existing `그냥! 지금 하면 돼!`
- supporting copy short and functional.
