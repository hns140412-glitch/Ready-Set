최종 홈 UI 적용 방식

- 사용자가 확정한 최종 홈 UI 이미지를 'home-final-master.png'로 직접 사용합니다.
- 따라서 홈 화면의 그라데이션, 스톱워치 비율, 카드 간격, 타이포그래피가 승인 이미지와 동일하게 표시됩니다.
- 재능/학교/영어, 설정 등 주요 영역에는 투명한 실제 버튼 영역을 올려 기능을 연결했습니다.
- 설정 화면의 이름 변경 및 음악 설정 기능은 기존대로 유지됩니다.
- START 이후 작전 설정/집중 화면도 기존 기능을 유지합니다.

START_PC_TEST.bat 더블클릭
