Ready & Set PWA - PC 로컬 확인

1. ZIP 파일을 먼저 압축 해제하세요.
2. 압축 해제한 폴더에서 START_PC_TEST.bat 을 더블클릭하세요.
3. Windows 기본 PowerShell로 로컬 서버가 실행됩니다.
4. 브라우저가 자동으로 http://localhost:8080/ 을 엽니다.
5. 확인을 끝낼 때 서버 창을 닫으면 됩니다.

중요:
- 이 절차는 로컬 확인용이며 DEVICE_VERIFIED 또는 PRODUCTION_VERIFIED 근거가 아닙니다.
- Python, Node.js, Netlify CLI 설치가 필요 없습니다.
- index.html을 직접 더블클릭하지 마세요.
- 8080 포트가 사용 중이면 자동으로 8081을 시도합니다.
