Ready & Set is the child's learning execution **BASE CAMP** and session orchestrator.

Current product authority:

- `READY_SET_RUNTIME_STATE_MODEL.md`

## Current role

Primary flow:

`ASSIGNMENT FACT → LEARNING MASTER → LEARNING UNIT → PLANNER → DATED TODO → TODAY → CHILD SELECT → SESSION → PER-TASK RESULT → PROGRESS/CARRY-OVER → LEARN/REPLAN`

Ready & Set is **not** a "Time Attack" product. Timing is an execution aid inside the learning/session system.

Ready owns the shared learning session. Vocabulary/retrieval work may route to Hide & Seek, and expression/writing/speaking work may route to Snap & Pop while preserving the same session/task/lap context.

## Authority boundary

- Parent: capture/input/confirm/support
- Learning Master: interpret/decompose/load metadata
- Planner: dated allocation authority
- Child: allowed fact input, TODAY selection, execution and outcome report

Project behavior must remain compatible with the TAKY Learning OS and Learning App Family contracts.

`CODED != CI_VERIFIED != RUNTIME_VERIFIED != DEPLOYED != DEVICE_VERIFIED != PRODUCTION_VERIFIED`

A merged commit, static package or hosted URL does not by itself prove real-device or production behavior.
