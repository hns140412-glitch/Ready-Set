타임어택 PWA - UI 테스트 체크리스트
=================================

[ ] 홈 상단 타이틀이 잘리지 않는다
[ ] 로즈골드 스톱워치가 정상 표시된다
[ ] 스톱워치 아래 핑크골드 그라데이션이 자연스럽다
[ ] 카드 아래 불필요한 긴 빈 공간이 없다
[ ] 재능 / 학교 / 영어 카드가 같은 폰트 체계다
[ ] 학교 아래 설명이 "과제"다
[ ] 영어 아래 설명이 "학습"이다
[ ] 375px 폭에서 레이아웃이 깨지지 않는다
[ ] 390px 폭에서 최종 UI 비율과 가깝다
[ ] 430px 폭에서도 카드 폭이 과하게 넓어지지 않는다

[ ] 작전 설정에서 과목 변경이 된다
[ ] 과제 양/단위 변경이 된다
[ ] 목표시간 15/25/40/60 선택이 된다
[ ] BGM 선택창이 열린다
[ ] essential;가 표시된다

[ ] START 시 타이머가 시작된다
[ ] 로컬 BGM이 재생된다
[ ] 잠깐 멈춤 시 음악과 집중시간이 멈춘다
[ ] ISSUE 시간이 별도로 기록된다
[ ] 다시 집중하기가 동작한다
[ ] 완료 결과가 나온다

[ ] 설정에서 이름을 저장할 수 있다
[ ] 새로고침 후 이름이 유지된다
[ ] 설정에서 기본 음악을 바꿀 수 있다
[ ] 새로고침 후 기본 음악이 유지된다

문제 발견 시:
- 화면 캡처
- 브라우저/화면 폭
- 어떤 버튼을 누른 직후인지
이 세 가지를 같이 기록하면 수정하기 쉽습니다.
