실기기에서 데이터 입력부터 TODAY → Mission → Focus → Result → Carry-over까지 한 번에 검증하기 위한 전용 진입점입니다.

기기 상태

1. 테스트 데이터 준비

기존 사용자 데이터와 구분되는 DEVICE_QA_ ID만 생성합니다. 기존 Planner 데이터를 지우지 않습니다.

2. 아이폰에서 실제 진행

  1. 아래 버튼으로 Ready & Set 본앱을 엽니다.
  2. Mission/TODAY에서 DEVICE QA · 과학 지층과 화석을 선택합니다.
  3. Focus를 시작하고 5~10초 실제 실행합니다.
  4. 완료 시 일부 남음(PARTIAL)으로 종료합니다.
  5. 다시 이 Device QA 화면으로 돌아와 결과 읽기를 누릅니다.
