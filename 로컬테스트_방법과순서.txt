타임어택 PWA - 로컬 테스트 방법
================================

이 폴더는 PC에서 타임어택 PWA를 실제 웹앱처럼 확인하기 위한 테스트용 패키지입니다.

[가장 쉬운 방법 - Windows]
1. ZIP 압축을 풉니다.
2. 압축을 푼 폴더 안의 "1_로컬테스트_시작.bat" 을 더블클릭합니다.
3. 검은 창이 열리고 로컬 서버가 실행됩니다.
4. 브라우저가 자동으로 http://localhost:8080 을 엽니다.
5. 테스트가 끝나면 검은 창에서 Ctrl + C 를 누르고 Y를 입력합니다.

※ Python이 설치되어 있어야 합니다.
※ 설치 여부 확인: 명령 프롬프트에서 python --version

[화면 확인 순서]
1. 홈 화면
   - 핑크골드 배경/그라데이션
   - 로즈골드 스톱워치 이미지
   - 재능 / 학교 / 영어 카드
   - 학교 설명은 "과제", 영어 설명은 "학습"

2. 작전 설정
   - 과제 분류 선택
   - 세부 과목 선택
   - 과제 양 입력
   - 목표 시간 선택
   - BGM 선택 확인
   - 작전 공유 버튼 확인

3. 집중 화면
   - START 후 타이머 동작
   - 선택한 BGM 재생
   - 잠깐 멈춤
   - ISSUE 사유 선택
   - 다시 집중하기
   - 완료했어요

4. 설정 화면
   - 이름 입력 후 저장
   - 새로고침 후 이름 유지 확인
   - 기본 음악 변경
   - 새로고침 후 음악 설정 유지 확인

5. 반응형 확인
   - Chrome에서 F12
   - 상단의 모바일/태블릿 아이콘 클릭
   - iPhone 14 / 15 계열 또는 폭 390px 정도로 확인
   - 375px / 390px / 430px 폭도 각각 확인

[중요: 일반 로컬 테스트에서 다른 점]
"1_로컬테스트_시작.bat"은 Python의 간단한 웹서버를 사용합니다.
따라서 화면, 버튼, 로컬 저장, 일반 타이머, 로컬 BGM 테스트에는 적합합니다.

하지만 아래 항목은 Netlify 환경과 100% 동일하지 않을 수 있습니다.
- /netlify/functions/time 서버시간 함수
- Netlify 배포 환경
- Google OAuth / Google Calendar
- 일부 PWA 설치 동작
- iPhone 잠금 상태의 YouTube 재생

이 기능까지 확인하려면 아래 "Netlify 방식 테스트"를 사용하세요.

[Netlify 방식 테스트 - 선택 사항]
준비:
1. Node.js 설치
2. 터미널에서 아래 명령 실행
   npm install -g netlify-cli

실행:
1. 이 폴더를 엽니다.
2. "2_Netlify방식_테스트.bat"을 더블클릭합니다.
3. 처음 실행할 때 Netlify 로그인을 요구할 수 있습니다.
4. 표시되는 localhost 주소로 접속합니다.

이 방식에서는 netlify/functions/time.js도 함께 실행됩니다.

[YouTube BGM essential;]
essential; 항목은 사용자가 지정한 YouTube 재생목록을 임베드합니다.
인터넷 연결이 필요하며, YouTube 외부 재생 허용 상태에 따라 동작이 달라질 수 있습니다.
피아노/물방울/자연음/Lo-fi는 로컬 파일이므로 인터넷 없이도 테스트할 수 있습니다.

[문제가 생기면]
- 화면 상단 이미지가 깨짐:
  index.html을 직접 더블클릭하지 말고 반드시 .bat 파일로 서버를 실행하세요.

- localhost가 열리지 않음:
  Python 설치 후 다시 실행하세요.
  또는 명령 프롬프트에서:
  python -m http.server 8080

- 8080 포트 사용 중:
  "3_로컬테스트_8081.bat"을 실행하세요.

- 변경 내용이 안 보임:
  Ctrl + Shift + R 로 강력 새로고침하세요.
  PWA 캐시가 남아 있다면 Chrome 개발자도구 > Application > Storage > Clear site data 실행 후 다시 확인하세요.
